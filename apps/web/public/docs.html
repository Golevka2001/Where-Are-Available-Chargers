Where Are Available Chargers API (5.2.0)

Download OpenAPI specification:

东南大学充电桩实时状态查询服务。提供三个校区（九龙湖、四牌楼、丁家桥）的充电桩实时状态、天气和历史记录查询。

CORS

所有 API 端点均支持跨域请求（Access-Control-Allow-Origin: *）， 并响应 OPTIONS 预检请求（返回 204）。

校区 ID

ID 校区
jiulonghu 九龙湖
sipailou 四牌楼
dingjiaqiao 丁家桥

插座状态

值 含义
0 占用（使用中）
1 空闲
2 故障

内容协商

首页（/）支持 Accept: text/markdown 请求头， 返回 Markdown 格式的站点摘要（包含所有 API 端点列表和页面链接）。

History

查询校区充电桩历史记录

支持两种查询方式（二选一）：

  • 预设范围：使用 range 参数
  • 自定义时间段：使用 start 和 end 参数（Unix 毫秒时间戳）

最大查询范围为 7 天。若自定义时间段超过 7 天，开始时间会被自动截断。 预设范围对应的秒数：1h = 3600s，6h = 21600s，24h = 86400s，7d = 604800s。

path Parameters
campusId
required
string
Enum: "jiulonghu" "sipailou" "dingjiaqiao"

校区 ID

query Parameters
range
string
Default: "24h"
Enum: "1h" "6h" "24h" "7d"

预设时间范围（与 start/end 互斥）

start
integer

自定义开始时间（Unix 毫秒时间戳，需与 end 同时使用）

end
integer

自定义结束时间（Unix 毫秒时间戳，需与 start 同时使用）

Responses
